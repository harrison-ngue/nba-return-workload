# Uploading this repository to GitHub without using the command line

1. Create/sign in to a GitHub account.
2. On GitHub, click **+** (top right) -> **New repository**.
3. Repository name: `nba-return-workload` (or similar).
4. Choose **Public**.
5. Do **not** initialize with a README, `.gitignore`, or license; those are already included here.
6. Click **Create repository**.
7. On the empty repository page, click **uploading an existing file**.
8. Unzip the GitHub-ready ZIP you received from ChatGPT. Open the `nba-return-workload` folder.
9. Drag the repository contents into the GitHub upload window. Each included file is below the normal browser-upload single-file limit; the redundant 29-MB Excel workbook was intentionally omitted.
10. Wait until the file list finishes loading, enter a commit message such as `Initial open-source release for MIT Sloan submission`, and click **Commit changes**.
11. Return to the repository homepage and confirm that `README.md`, `data/`, `code/`, `results/`, `figures/`, `tables/`, and `docs/` are visible.
12. Open `README.md` on GitHub and edit the Contact section plus the placeholder author/citation fields before submission.
13. Copy the repository URL from your browser. That is the link to provide to the Sloan submission form.

If GitHub's browser uploader rejects a folder upload in your browser, upload the files in groups (root files first, then each subfolder) or use GitHub Desktop; the repository contents themselves do not need to change.
