# Code notes

The extraction notebook is the canonical source-data construction record. The project evolved through several analysis iterations. `10_comprehensive_analysis_archive.py` is retained for transparency but predates the final cross-season longitudinal reconstruction and should not be treated as the sole exact final model script. The final cohort/estimand is specified in `../docs/FINAL_LONGITUDINAL_ANALYSIS_SPEC.md`, while frozen final estimates are in `../results/`.

The Sloan figure scripts contain final reported estimates for annotation and use the public source bundle for descriptive panels. They should not be interpreted as manufacturing inferential results from hard-coded values; the inferential targets are separately published in `results/`.
