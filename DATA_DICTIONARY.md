# Human-readable data dictionary

For the full machine-generated column inventory, see `data/DATA_SCHEMA.csv`.

## `combined_injury_episodes.parquet`

One row per validated season-level injury/return-to-play episode generated by the source pipeline before the final cross-season reconstruction.

Important fields include:

- `episode_id` — unique source-pipeline episode identifier.
- `player_id`, `player_name` — player identifiers.
- `season` — NBA season.
- `games_missed` — scheduled games missed in the injury episode.
- `pre_median_minutes` — preinjury playing-time baseline in the source pipeline.
- `primary_analysis_eligible` — source-pipeline eligibility flag.
- `return_minutes_ratio`, `post3_mean_minutes_ratio`, `post5_mean_minutes_ratio` — relative workload measures.
- `ramp_slope_minutes_per_game`, `max_positive_minute_step_first5`, `ramp_deficit_auc_first5`, `games_to_90pct_baseline` — ramp descriptors.
- `return_team_is_b2b`, `return_travel_km`, `b2b_count_first5_team_games_post`, `travel_km_first5_team_games_post` — return context.
- `subsequent_any_injury_absence_within_14d/30d/60d` — subsequent injury-related absence proxy outcomes.
- recurrence/same-region fields — public-report anatomical proxies for later events.

## `combined_rtp_episode_game_windows.parquet`

Game-level rows surrounding each source episode. Important fields include `episode_id`, `game_date`, `relative_game`, `minutes`, `played_actual`, injury-report reason/status fields, schedule context, performance, and window indicators.

## `combined_player_game_master.parquet`

Harmonized player-by-scheduled-game master table. This is the most flexible source table for independently rebuilding longitudinal chronologies across season boundaries.

## `combined_all_absence_episodes.parquet`

All classified absence episodes, including injury and noninjury reasons. Useful for sensitivity analyses and alternative recurrence/continuation definitions.

## QC files

- `combined_qc_summary.csv` — season-level coverage summary.
- `combined_qc_gates.csv` — pass/fail QC gates.
- `age_enrichment_audit.csv`, `age_enrichment_unmatched.csv`, `age_manual_resolution_audit.csv` — age metadata audits.
